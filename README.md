# Rynix Salon — Premium Bridal Website

Elegant, mobile-first website for Rynix Salon (Premium Bridal Beauty Studio).

## Features
- Luxury cream / gold / espresso design matching the provided brand guide
- Fonts: Cormorant Garamond, Montserrat, Allura
- Home, Services, Book, Gallery, About, Contact pages
- Booking form → opens WhatsApp with pre-filled message
- Contact form → opens WhatsApp with pre-filled message
- Floating WhatsApp + Instagram buttons
- Fully responsive
- Pure HTML / CSS / JS — no backend needed

## How to Host for FREE

### Option 1: Netlify (easiest)
1. Go to https://app.netlify.com
2. Drag & drop the entire `rynix-salon` folder
3. Your site will be live in seconds with a free URL
4. Optional: connect a custom domain later

### Option 2: GitHub Pages
1. Create a new GitHub repository
2. Upload all files
3. Go to Settings → Pages → Deploy from main branch
4. Site will be available at `https://yourusername.github.io/repo-name`

### Option 3: Vercel / Cloudflare Pages
Similar drag-and-drop or Git upload process.

## Customisation Notes
